# Workshop and demo source

Each workshop, demo, starter project, or sample application gets its own subdirectory here.

Keep a project self-contained: source, lockfile, README, and project-specific checks belong together. Do not put reusable agent procedures here; put those in `../skills/`. Do not put participant-facing landing pages or deck experiences here; put those in `../web/`.
